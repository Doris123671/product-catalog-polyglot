# SpendWise Dashboard Shell

## What I built
This project adds a responsive SpendWise dashboard landing page with a sidebar navigation, header, summary area, and six budget category cards. The layout uses CSS Grid for the overall shell and Flexbox for the header, sidebar, and card content.

## Files
- index.html — dashboard structure and static content
- style.css — theme variables, responsive layout, card interactions, and dark mode support

## Features
- Responsive dashboard layout with a sidebar and main content area
- CSS Grid for the main page structure and card grid
- Flexbox for header, navigation, summary, and card alignment
- Hover and keyboard focus interactions for the cards
- Dark theme support via the prefers-color-scheme media query

## How to view it
Open index.html in a browser, or use a simple local preview server if you prefer.
